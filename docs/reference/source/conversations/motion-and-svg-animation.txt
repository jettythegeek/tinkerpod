## What we can use

There are a few ways to do it depending on where it will run.

### 1. SVG animation

Good for:

* icons
* badge bursts
* rays
* small celebratory effects
* scalable lightweight vector animations

Can be done using:

* SMIL animation inside SVG
* CSS animation on SVG
* JavaScript-driven SVG animation

### 2. Lottie animation

This is even more common in apps.

Good for:

* badge unlock celebrations
* rank-up moments
* success checkmarks
* spark bursts
* mascot animations

Lottie works very well in **React Native**.

Usually workflow is:

* animation designed in After Effects
* exported with Bodymovin as JSON
* used in app with `lottie-react-native`

But I can also help define the motion concept and structure.

### 3. React Native animations

For UI-driven effects in Expo:

* Reanimated
* Moti
* Animated API

Good for:

* progress bar fill
* XP count-up
* scale pop
* floating badge reveal
* leaderboard climb animation
* modal entrance with sparkles

## My recommendation for TinkerPod

Use a mix:

### Use Lottie for:

## Example: badge unlock flow

When a child unlocks a badge:

1. screen dims slightly
2. badge pops into center
3. circular ring expands
4. spiral rays rotate outward
5. stars/confetti appear
6. text fades in:

   * **Badge Unlocked!**
   * **Game Maker**
7. XP counter animates upward
8. “Continue” button appears

That can absolutely be done.

## Example: rank-up flow

When a child reaches next rank:

1. current rank icon glows
2. progress bar fills
3. burst animation
4. new rank badge flips/scales in
5. rays circle around it
6. sound plays
7. message shows:

   * **You are now a Pod Champion!**

Very doable.
