# Landing page plan

Source PRD: sections 5 and 21.

## Pages

Home, About, Programs, Pricing, Schools, Camps, Young Founders, FAQ, Contact, Privacy, and Terms. The public site has no login.

## Home sequence

Hero → what TinkerPod is → how it works → learning tracks → mentor-led pods → projects/outcomes → pricing → Schools/Camps/Young Founders pathways → FAQ → conversion CTA → contact/footer.

## Conversion

Pre-launch: Join Waitlist, WhatsApp, Register Interest. Post-launch: app-store links and Get Started. All forms require consent copy, validation, spam protection, success/failure handling, and source attribution.

## Technical requirements

Responsive, accessible, metadata/structured data, sitemap/robots, optimized transparent SVG/PNG brand assets, image performance budgets, analytics consent, and no child personal data collection.
