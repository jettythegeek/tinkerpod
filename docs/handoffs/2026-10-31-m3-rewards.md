## 1. What Shipped in M3

### Design Pack & Screen Updates (`Add design pack` + `M3.0`)
- Merged `design-pack.tar.gz` and `new-screens-33-48.tar.gz` into `design/` and regenerated `design/MANIFEST.md` (verified by `node scripts/verify-design-manifest.mjs` and `RepoHygieneTest`).
- **Quiz Anti-Farming (`M3.0`)**:
  - `POST /api/v1/kid/quizzes/{quiz}/attempts` starts an open attempt (counted against `max_attempts`).
  - `POST /api/v1/kid/quizzes/{quiz}/check` requires an open attempt; the first answer to each question in that attempt is saved in `quiz_attempt_answers` and is the only answer that scores. Retries allow learning after `"Not quite. Try again!"` with `0` points.
  - `POST /api/v1/kid/quizzes/{quiz}/attempts/{attempt}/finish` (or `POST /api/v1/kid/quizzes/{quiz}/attempts` with `action=finish`) scores the attempt server-side from saved first answers.
  - Removed duplicate routes (`/submit`, `/kid/profile/username`, and `GET .../signed-url`).
- **Demo Seeder & Enrollment CLI (`M3.0`)**:
  - `DatabaseSeeder` runs `DemoCurriculumSeeder` only in `local` and `testing` environments and no longer auto-enrolls every child.
  - Added `php artisan tinkerpod:enroll {username} {pod}` (`EnrollChildCommand`).
- **Mockup Screens & `fx03` Asset (`M3.0` + `M3.13`)**:
  - Rebuilt and verified all 14 M3 screens (`01`, `02`, `03`, `04`, `07`, `10`, `33`, `38`, `39`, `40`, `44`, `45`, `46`, `47`) with Nunito loaded and Lucide icons (`House`, `BookOpen`, `Hammer`, `Trophy`, `Smile` on bottom nav).
  - Replaced hand-drawn SVG paths in `Fx03CorrectWrong.tsx` with `design/fx/svg/fx03-correct-wrong.svg` (`design/fx/svg/fx03-correct-wrong-static.svg` when `reducedMotion`/`reducedEffects` is active).
  - Removed the duplicate `App\Services\LearningAccess` class so only `App\Domain\Learning\LearningAccess` remains.

### Immutable Reward Ledger & Balance Projection (`M3.1`)
- Created `reward_ledger` (`child_id`, `currency` [`xp`, `coins`, `gems`], `amount`, `source_type`, `source_id`, `rule_version`, `idempotency_key` UNIQUE, `reason`, `adjusted_by_user_id`, `created_at`) and cached `reward_balances` (`child_id`, `currency`, `balance`, `updated_at`).
- Enforced append-only immutability on `RewardLedger` (updates and deletes throw `LogicException` in model hooks and are tested in `RewardLedgerImmutabilityTest`).
- Added `php artisan tinkerpod:rebuild-reward-balances {--verify}` (`RebuildRewardBalancesCommand`) to rebuild and verify `reward_balances` strictly from `reward_ledger`.

### Server-Authoritative `RewardService::award(event)` (`M3.2` – `M3.5`)
- Implemented `App\Domain\Rewards\RewardService::award(RewardEvent)` returning `RewardResult` (`ledger_entries`, `totals`, `level_change`, `new_badges`, `streak_change`, `new_title`, `presentation_tier` [`small`, `level_up`, `badge`, `streak`, `big`], `was_replayed`).
- Wired `RewardService::award` into first-time lesson completion (`PUT /api/v1/kid/lessons/{lesson}/progress` and quiz-gated lesson completion) and first-time quiz pass / 100% perfect quiz (`POST /api/v1/kid/quizzes/{quiz}/attempts/{attempt}/finish`).
- Added `RejectClientRewardFields` validation rejecting any client-sent reward fields (`xp`, `coins`, `gems`, `level`, `streak`, `badges`, `title`, `reward`, `rewards`, `amount`, `points`, `stars`, `score`) with HTTP `422`.
- Created versioned `reward_rules`, `reward_levels` (Levels 1–30), `naija_titles` (`Cody Coda` -> `Odogwu`), `badges`, `child_badges`, `streak_settings`, and `child_streaks`, plus migration `2026_10_31_102000_drop_reward_preview_columns_from_lessons_table.php` so `Lesson::rewardsPreview()` computes lesson reward previews dynamically from active `reward_rules`.
- Implemented `Africa/Lagos` midnight streak evaluation with configurable `grace_days` and kind `streak_paused` state (`"Captain Jetty kept your spot warm! Do one lesson today to start a new streak."`).

### Staff Adjustments, Kid Rewards/Profile Endpoints & Filament Admin (`M3.6` – `M3.8`)
- Implemented `RewardService::adjust(...)` gated by `rewards.adjust`, requiring a non-empty `reason`, appending a `staff_adjustment` row to `reward_ledger`, and writing an `audit_logs` entry (`action = 'reward.adjusted'`).
- Added `GET /api/v1/kid/rewards` and `GET /api/v1/kid/profile` (`KidRewardsController`) and wired live gamification into `GET /api/v1/kid/home` with query-count assertions (`<= 8` queries on `/kid/rewards`, `<= 10` on `/kid/profile`, `<= 12` on `/kid/home`).
- Built Filament admin resources using Heroicons only (`RewardRuleResource`, `RewardLevelResource`, `NaijaTitleResource`, `BadgeResource`, `StreakSettingResource`, and read-only `RewardLedgerResource` with the `adjust_balance` modal action).

### Mobile Live HUD, Celebrations, OpenAPI & Property Tests (`M3.9` – `M3.12`)
- Deleted `app/src/features/kid/gamificationStub.ts` and wired live M3 rewards/profile data across `KidHomeScreen`, `JourneyMapScreen`, `RewardsScreen`, `KidProfileScreen`, `LessonDetailScreen`, and `QuizScreen`.
- Built `StreakFlameIdle.tsx` (`fx10-streak-flame-idle.svg` / `fx10-streak-flame-idle-static.svg`) and `RewardCelebrationModal.tsx` (`fx01`, `fx02` + `pip-celebrate`, `fx05`, `fx08` with native `<Text testID="reward-celebration-badge-name">` overlay, `fx06` + `fx07`, and kind `streak_paused` wakeup with `pip-sleepy` -> `pip-sleepy-wake-static.svg`), honouring `muted`, `reducedMotion`, and `reducedEffects`.
- Updated `docs/openapi.yaml` (`M3.11`) and added `RewardPropertyAndConcurrencyTest.php` and `m3-rewards-and-celebrations.test.tsx` (`M3.12`).
