### Intentional Differences Required by M2 Rules:
1. **Captain Jetty Naming Rule**: Where the legacy HTML/PNG mockups say `"Pip"` (`"Let's keep exploring with Pip!"`, `"Teach Pip to repeat actions"`, `"Pip's Hint"`), the app renders **"Captain Jetty"** (`"Let's keep exploring with Captain Jetty!"`, `"Teach Captain Jetty to repeat actions"`, `"Captain Jetty Hint"`).
2. **Kid-Safe Positive Copy (No Streak Shaming)**: In `10-teen-home.png`, the banner in the static mockup says `"Your 23-day streak ended"` / `"Use 1 Streak Freeze (40 Gems) or do one lesson today to restart"`. Per Hard Rule #5 (*"Show no failure or streak shaming"*) and M3 scoping, the senior home screen renders `"Ready for today's coding session — Do one lesson today with Captain Jetty."`
3. **M3 Gamification Stubs (`gamificationStub.ts`)**: XP, coins, gems, streaks, levels, and daily missions belong to Milestone M3. Their layout slots are preserved in `KidHomeScreen` (junior & senior) and `JourneyMapScreen`, populated from `getGamificationStub()` with zeroed placeholders (`0d`, `0`, `0 Coins`, `0 Gems`, `Level 1 · Starter Explorer`, `0 / 0 XP`, and `"Missions and XP rewards arrive in Milestone M3"`).

- **Local Emulator Check**: Neither `adb` nor the Android Studio AVD `emulator` binary is installed on this Windows workstation (`ANDROID_HOME` is not set). All screens were verified via Jest + React Native Testing Library, TypeScript strict check, and `360 dp` / `412 dp` viewport rendering.
- **How to Verify on Your Android Phone with Expo Go (`360 dp`)**:
  1. Ensure the Laravel API is running on your LAN IP (e.g., `cd api && php artisan serve --host=0.0.0.0 --port=8000`) and set `EXPO_PUBLIC_API_URL=http://<YOUR_LAN_IP>:8000/api/v1` in `app/.env`.
  2. Seed the demo curriculum if not already seeded:
     ```bash
     cd api
     php artisan migrate --seed
     ```
  3. Start the Expo dev server from `app/`:
     ```bash
     cd app
     npx expo start
     ```
  4. Open **Expo Go** on your Android phone, scan the QR code printed in the terminal, and verify:
     - **Welcome Screen**: Confirm `"Learn to code with Captain Jetty!"` and both CTA buttons fit cleanly at `360 dp`.
     - **Kid Login & PIN Pad**: Tap `"I'm a Kid"`, enter a child username or parent email/phone, pick the child profile, and verify the 4–6 digit PIN pad (`>= 60 dp` keys) logs into Kid Home.
     - **Kid Home (`junior` vs `senior`)**: Confirm the junior layout (`01-kid-home`) or senior layout (`10-teen-home`), tap `"See map →"` to open the **Journey Map**, tap `"Continue"` to open **Lesson Detail (`Repeat and Count`)**, play the `"Watch intro"` video, and tap `"Start Lesson"` to complete the **`range()` Quiz** with `fx03` feedback.
